# dashboard-studies
This is my dashboard (german language). I use for keeping my notes for the upcoming events and exams during my studies prepared. 
It has the following features: 
- Welcoming text with time, different settings like design settings
- Big task plan where you can set the upcoming classes and add notes (preparations etc.) to it
- Nice big display of the next upcoming task
- Display of upcoming exams
- Synchronisation with the cloud for keeping your notes and events organized across your devices
